# Agent instructions

## Project checklist

- `todo.md` is the single authoritative checklist for this project. Read it at
  the start of every task, before making changes.
- Follow the "Maintenance instructions" section in `todo.md`.
- After authorized work changes project state, update `todo.md` before
  responding: tick or reopen the relevant checkboxes, add a short dated progress
  note with evidence, refresh "Next steps", and update the "Last updated" date.
- Leave a task unchecked if it hasn't been verified, and say why in its note.
  Never record results that weren't actually observed.
- The backlog in `todo.md` does not authorize work. Only do what the current
  request asks; add newly discovered tasks to `todo.md` instead of doing them.
- Don't keep a second checklist anywhere else.

## Project notes

- Static site served by GitHub Pages from the repo root (`index.html`) of
  `jyotibikas/tryclaude`, expected at https://jyotibikas.github.io/tryclaude/.
- No build step or dependencies; edit the HTML directly.
- Don't push, change repository settings, or publish without the user's
  explicit approval.
